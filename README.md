# London Crawl Planner

Walking pub crawls through London's sights. Plan, save and share routes, and
get the story of each stop as you arrive.

The app lives in [`v2/`](v2/README.md); `docs/` is the built copy served by
GitHub Pages.

```bash
npm run build && npm run serve   # http://localhost:8000
npm test                         # unit tests
```
